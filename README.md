If you have some knowledge that might be useful for someone, checkout the [Contribution Guide](./CONTRIBUTING.md).

## Using the QR with an LLM assistant

The QR is also available as a skill, so assistants like Claude Code can consult it when answering questions. In Claude Code:

```
/plugin install log-qr --marketplace log-ufpb/qr
```
